# NeuroCAD candidate completion report

**Updated:** 2026-09-06  
**Declared source version:** 0.5.0a6  
**Release status:** local candidate gates passed; not a public release receipt

## What is retained and real

The maintained project is a bounded prompt/JSON-to-OpenSCAD compiler surrounded
by a disconnected historical research archive. The frozen directory
`research/runs/NC-RUN-2026-09-03-FULL` contains the recorded controlled study,
including its datasets, programs, metrics, STL files, renders, validation files,
and artifact manifest. Its recorded controlled outcomes remain historical
evidence for that run.

That frozen manifest does **not** bind itself to a Git commit, package version,
source-tree digest, dependency-lock digest, or immutable OpenSCAD binary. Current
source files postdate it. It therefore cannot be used as proof that the current
a6 candidate reproduces those outcomes.

Historical negative evidence also remains in scope: legacy root kernels are
incompatible, the old pseudo-STEP path is not STEP, no trained model exists, and
the old typed-parser mechanism claim remains falsified.

## Frozen controlled outcomes

The historical run records:

- NC-EXP-001: 240 controlled compiler tasks and three baselines;
- NC-EXP-002: 1,000 generated IR programs;
- NC-EXP-003: 240 entries across eight malformed-input fixtures;
- NC-EXP-004: 200 constructed constraint corruptions;
- NC-EXP-005: 200 automated parameter edits;
- NC-EXP-006: 240 retained OpenSCAD/STL/render records;
- NC-EXP-007: hierarchy-depth boundary checks.

These are synthetic controlled-regression results. Repeated malformed fixtures
are not independent natural-language observations, and topology/extents checks
are not full feature equivalence or manufacturing validation.

The frozen hashes printed in the old report remain available inside the frozen
run and its environment receipt. They are deliberately not relabelled as hashes
of current source, current results, or a6 distributions.

## Fresh reproduction

With CPython 3.12.14 and native OpenSCAD installed:

```bash
./scripts/reproduce_research.sh
```

The script creates a uniquely named output directory, a fresh disposable virtual
environment, disables artifact reuse through the recorded research config,
runs all quality gates, builds fresh distributions outside the historical
`dist/`, and smoke-tests the exact wheel. It refuses to write into the frozen
canonical run. See `REPRODUCIBILITY.md` for headless/Xvfb requirements and the
deterministic-versus-runtime artifact boundary.

## Claims still unsupported

No public/tagged release, external replication, learned model, general language
understanding, sketch/image input, BREP/STEP reconstruction, arbitrary topology
equivalence, numerical constraint solving, manufacturability proof, simulation,
human usability result, or safety certification is established by this report.

## Closure rule

The candidate is complete only after one clean Git revision passes the integrated
matrix, generates a fresh non-resumed research run, builds and clean-installs its
exact distributions, emits `RELEASE_PROVENANCE.json`, and is independently
installable from the public tag. Until then the release remains pending.
