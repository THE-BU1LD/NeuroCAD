# Model card: not applicable

NeuroCAD v0.5.0a6 contains no trained model in its supported pipeline. It is a deterministic compiler. Therefore there are no parameters, FLOPs, training data, optimizer settings, training seeds, or checkpoints to report.

Historical neural/SDF modules are disconnected research artifacts and are not presented as the method. The nearest-neighbor comparator in NC-EXP-001 is an evaluation baseline fitted only to train-labelled examples, not a NeuroCAD component.

Adding a model would create a new scientific task and require an independently licensed dataset, frozen splits, multi-seed training, compute/parameter-matched baselines, checkpoints, and new experiment IDs. None is fabricated here.
